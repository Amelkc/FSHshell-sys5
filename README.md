# FSHshell-sys5
Projet réalisé en binôme dans le cadre du cours de système d'exploitation en L3 à l'université Paris-Cité (2025-2026)

## Sujet : `fsh`, un petit shell avec des boucles `for`

Le but du projet est de programmer un interpréteur de commandes interactif reprenant quelques fonctionnalités plus ou moins classiques des shells usuels : outre la possibilité d'exécuter toutes les commandes externes, `fsh` devra proposer quelques commandes internes, permettre la redirection des flots standard ainsi que les combinaisons par tube, adapter le prompt à la situation, et supporter les structures conditionnelles et un certain type particulier de boucles.

## Compilation et lancement du projet

```
make run

```
## Compilation et lancement des tests

```
make test

```
